# Itinerary — Osaka 2026（護妻輕鬆版 v1）

## Core Rules
- 旅伴不想走太多路、也不想搭車太久；每天只排 1 個主軸 + 1 個輕鬆備案。
- 移動優先順序：計程車 > 指定席 / 少轉乘電車 > 一般地鐵。
- 每天中段安排坐下休息，避免久站排隊。
- 餐廳盡量提前訂位；現場排隊名店先降級為備案。
- USJ 以氣氛、拍照、表演為主，不硬玩設施。

---

## Day 1 — 2026-05-23（六）抵達大阪：飯店休息 + 中之島河畔

### Morning / Flight
- TPE 09:30 → KIX 13:20

### Afternoon
- 13:20 抵達 KIX，入境、領行李。
- 護妻交通建議：
  - A 案：JR HARUKA 到大阪站 / 梅田，再計程車到飯店。
  - B 案：利木津巴士到梅田周邊，再計程車到飯店；行李處理更輕鬆。
  - 不建議：拖行李轉多段地下鐵。
- 16:00 左右：相鐵FRESA INN 淀屋橋 check-in，休息。

### Evening
- 17:30 中之島公園 / 玫瑰園輕散步。
  - 飯店位於淀屋橋站附近，中之島很近，適合短距離散步。
  - 5 月下旬通常仍可看玫瑰，但花況出發前再確認。
- 晚餐候選：
  - 首選：GARB weeks。中之島公園內，河畔感好，週六晚餐建議訂位；確認室內座位。
  - 備案：梅田百貨美食街 / 餐廳樓層。若想吹冷氣、坐得舒服，可計程車 / 地鐵一站移動。
  - 詳細餐廳清單見 `restaurants.md`。

### Backup / Rain Plan
- 直接去梅田百貨美食街晚餐，吃完計程車回飯店。

## Day 2 — 2026-05-24（日）京都祇園：京阪 Premium Car + 人力車

### Morning
- 09:30 從飯店出發到京阪淀屋橋站。
- 搭京阪特急 Premium Car：淀屋橋 → 祇園四條。
  - Premium Car 是指定席，適合這趟；可在車站或平台售票機購買。
  - 建議抓約 55–60 分鐘車程。

### Late Morning
- 11:00 京都人力車體驗。
  - 上車點建議：祇園 / 八坂神社附近。
  - 路線主軸：花見小路、白川巽橋、建仁寺周邊。
  - 原則：以拍照和氣氛為主，不安排清水寺上坡。

### Lunch
- 12:30 祇園周邊午餐。
  - 首選：祇園 藤寅 / Gion Fujitora。祇園四條站近、蒸籠和食、較適合坐下慢慢吃；建議訂位。
  - 備案：Gion Ichiho。創意壽司卷套餐，離站近，午餐分時段，建議訂位。
  - 避免排隊名店。

### Afternoon
- 14:30 日式甜點 / 咖啡廳坐著休息。
  - 首選：鍵善良房 四条本店。
  - 備案：茶寮都路里 祇園本店。
  - 若排隊太長，直接換店，不硬等。
  - 詳細餐廳清單見 `restaurants.md`。

### Evening
- 16:30 搭京阪 Premium Car 回淀屋橋。
- 晚餐：飯店附近 / 北浜 / 淀屋橋簡單吃。

### Backup / Rain Plan
- 京都改成「祇園午餐 + 甜點 + 短距離拍照」，人力車若雨勢大就取消或縮短。

## Day 3 — 2026-05-25（一）USJ：只感受氣氛，不硬玩設施

### Morning
- 09:00 飯店門口叫計程車前往 USJ。
  - 優點：避開通勤轉乘、人潮與站內走路。
  - 車程抓約 25–35 分鐘，視交通狀況。

### In Park Strategy
- 今日目標：拍照、逛商店、看表演、吃飯，不追刺激設施。
- 孕婦 / 低體力原則：
  - 入園先確認官方當日適合觀賞的表演與限制。
  - 避免雲霄飛車、劇烈晃動、需要長時間排隊的設施。
  - 看到椅子就休息，不用把票價玩回來。

### Suggested Flow
- 10:00 入園拍照、逛入口商店。
- 11:00 提早午餐，避開 12:00–13:30 尖峰。首選 Park Side Grille，備案 SAIDO；優先使用 USJ Priority Seating / 現場候位機制。
- 13:00 看室內 / 坐著為主的表演。
- 15:00 咖啡、甜點、商店補貨。
- 17:00–18:00 提早離園，避開閉園退場潮。

### Evening
- 回市區吃晚餐，優先選飯店附近或梅田百貨內餐廳。

### Backup / Low Energy Plan
- 如果早上狀態不好：USJ 延後入園或改成梅田室內購物 + 咖啡，USJ 當作下次再玩。

## Day 4 — 2026-05-26（二）寶寶用品採買 + 阿倍野 Harukas 夜景

### Morning
- 10:30 阿卡將本舖 大阪本町店。
  - 地址：大阪市中央區南本町 3-3-21。
  - 最近：本町站，御堂筋線；若用電梯，查 7 號出口較友善。
  - 營業時間通常 10:00–20:00，出發前再確認。
- 從淀屋橋到本町只有一站；若不想走站內，直接計程車也合理。

### Lunch
- 13:00 本町 / 心齋橋周邊午餐。
  - 原則：選可坐、不要排太久、離地鐵或計程車點近。
  - 避開 12:00–13:00 商務午餐尖峰；採買後 13:00 再吃較舒服。
  - 詳細餐廳策略見 `restaurants.md`。

### Afternoon
- 15:00 回飯店休息 60–90 分鐘，或直接往天王寺。
  - 我建議：買完東西先回飯店放戰利品，旅伴會舒服很多。

### Late Afternoon / Evening
- 16:30 前往阿倍野 Harukas 300。
  - 御堂筋線：淀屋橋 → 天王寺，單線直達，少轉乘。
  - 若已疲累：飯店 → Harukas 直接計程車。
- 17:00–18:30 展望台看夕陽 / 夜景。
  - 室內、可坐、冷氣足，適合低體力版。
- 18:30 晚餐：阿倍野 Harukas Dining 12–14F / 近鐵百貨內解決。
  - 候選：大阪 竹葉亭、花外楼、鐵板燒＆ワイン En，或現場挑舒服的店。
  - 詳細餐廳清單見 `restaurants.md`。
- 飯後回淀屋橋。

### Backup / Rain Plan
- 採買 + Harukas 都是室內，雨天照跑。
- 若太累：取消 Harukas，只做本町採買 + 飯店休息 + 附近晚餐。

## Day 5 — 2026-05-27（三）悠閒退房 + 回程

### Morning
- 09:30 睡到自然醒、整理行李。
- 10:30 飯店附近早餐 / 咖啡。
- 11:00 退房、確認行李與證件。

### Airport Transfer
- 班機：KIX 15:15 → TPE 17:30。
- 建議 13:15 左右抵達 KIX。
- 11:30 出發比較穩。
- 護妻交通建議：
  - A 案：計程車到梅田，搭利木津巴士直達 KIX；行李最輕鬆。
  - B 案：計程車到大阪站，搭 JR HARUKA 到 KIX。
  - 若有很多戰利品，優先巴士。

### Afternoon
- 13:15 抵達機場，報到、安檢、免稅店補貨。
- 15:15 起飛返台。

### Backup
- 若早上很累：取消早午餐，直接飯店退房 → 機場，在 KIX 吃。
